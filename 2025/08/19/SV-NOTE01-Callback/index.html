SV NOTE01-Callback

发表于 2025-08-19 更新于 2025-08-22

Background

    提高测试平台的可复用性，修改少量代码即可完成对整个测试平台的重新部署。

How to creat & use

    1.创建使用virtual function的function\task，这一步是为了在测试平台中留下钩子(hook),方便后期对平台进行修改；

    2.在base class中定义空的callback function，这些函数必须为virtual,且一般为空；

    3.派生base class，并实现需要用到的callback function;

    4.在测试平台的顶层，声明派生类，并覆盖基类。

NOTE

Abstract class

    1.使用virtual class进行定义；

    2.只可以被继承，无法实例化；

    3.如果virtual class内包含pure virtual function，派生类需要实现所有的pure virtual function才可被实例化。

pure virtual function

    1.纯虚方法只有定义没有实体，只能在virtual class中定义;

    2.virtual class中也可以定义virtual function和function.
