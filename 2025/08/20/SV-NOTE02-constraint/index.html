SV NOTE02-constraint

发表于 2025-08-20 更新于 2025-08-22

Background

    使变量在我们的控制之下随机产生满足要求的数值，得到更有效的激励。

How to use

    用rand\randc定义可以随机化的变量，使用randomize,随机化变量，在编译指令中加入seed(一个seed对应一种随机化结果)。使用constraint声明约束，或者在randomize时，用with语句补充约束。

Constraint Type

    1.soft constraint：前后取交集，若交集为空前面的constraint可以被后面的constraint覆盖掉；

    2.normal constraint：前后取交集，若交集为空编译器会报error；

Note

    1.with{}内的约束相当于补充约束条件到随即类中定义的约束，同样取交集，若为空，normal constraint报错，soft constraint被覆盖；

    2.类的继承中，派生类也可以继承基类的约束条件，派生类也可以重写基类的约束条件，同function\task相同。
