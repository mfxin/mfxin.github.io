background

  面向对象编程（OOP, Object Oriented Programming）是一种以“对象”为基本单元的编程范式，它将程序看作是现实世界事物的抽象模型，通过类、对象、封装、继承和多态等概念来组织代码，从而实现更接近自然运行模式的系统建模和开发。这种编程范式相对面向过程编程，通过将相关数据和函数捆绑到对象中，提高了代码的可重用性、可维护性和灵活性。

OOP术语

（1）类（Class）

  类是对象的模板或蓝图，定义了对象的属性（数据）和方法（行为）。

  类 ≈ 模板，对象 ≈ 模板生成的实例。

（2）对象（Object）

  类的实例化产物，是真实存在的个体。

  每个对象都有自己的一份属性值。

（3）封装（Encapsulation）

  将数据和操作数据的方法绑定在一起，隐藏内部细节，只对外暴露必要接口。

  好处：保证安全性，提高模块化。

（4）继承（Inheritance）

  一个类可以基于已有的类进行扩展，获得父类的属性和方法。避免重复代码，实现代码复用。

（5）多态（Polymorphism）

  同一接口，不同实现。让子类可以覆盖父类的方法，或者不同对象以相同方式调用但行为不同。

类的继承

  使用extends关键字，创建子类。子类中可以对父类的虚方法进行覆盖（绿皮书白皮书中将override翻译为重载，个人觉得还是要区分重载overload、覆盖override、重写overwrite，虽然这是在c++中才会严格区分的几个类相关的概念），具体的子类定义前面的code示例中已经给出。

  子类中包含父类中所有的成员变量及方法，子类中用this、super区分子类和父类的同名成员变量。可以理解为子类是父类的补充。父类是子类的子集。

类型转换

  向上类型转换和向下类型转换，对于“向上”和“向下”不同的地方可能有不同的定义，在此处相对于对象类型来定义向上类型转换和向下类型转化：

  1. 子类对象赋值给父类句柄，称为向上类型转换；
  2. 父类对象赋值给子类句柄，称为向下类型转换。

向上类型转换（upcasting）

  upcasting是安全的，这个很好理解，子类成员对于父类成员，父类是子类的子集，因此用父类句柄能够调用的方法子类中都有，不存在方法找不到的情况，因此upcasting是安全的。代码中可以直接用如下方式来实现向上类型转换。

向下类型转换（downcasting）

  downcasting是不安全的，这个也很好理解，与upcasting相反，若用子类句柄指向父类对象，子类句柄可能调用子类中存在而父类中不存在的成员，这就导致父类对象无法执行，因此downcasting是不安全的。

NOTE related $cast(p, c)

  $cast(p, c)指的是用p句柄指向c的对象。cast转换会检查两个条件：

  1. 检查句柄：c是否为p的派生类，或者具有派生关系，即c是p的子类，或者子类的子类（孙子类）都可以；

  2. 检查对象类型：p, c指向的对象的类型是否相同，如果前文中已经完成了p,c的向上类型转换，那么p指向的对象类型与c指向的对象类型相同（甚至是同一个对象），则也可以完成转换；

    两个条件满足其一，$cast返回1，否则转换失败返回0.
