SV NOTE03-coverage

发表于 2025-08-23 更新于 2025-08-26

background

    跟踪芯片验证工作的进度，判断验证工作是否完整，衡量哪些设计已经被验证过的指标。

Type

    1.代码覆盖率：是衡量验证进展的最简易的方式。它的作用是检查代码是否冗余，设计要点是否遍历，被检测的对象是RTL代码，而代码覆盖率的检测一般由工具自动生成的。包括：行覆盖率(Line coverage)、分支覆盖率(Branch coverage)、路径覆盖率(Path Coverage)、翻转覆盖率(Toggle coverage)、条件覆盖率(Conditional coverage)、有限状态机覆盖率(FSM coverage)。

    2.功能覆盖率：功能覆盖率是一个用户定义的度量标准，通过测试SPEC中的特性枚举多少已经被执行，衡量验证进度。

    3.断言覆盖率等。

How to use

    covergroup可以定义在module、class、program中，它可以采样任何可见的变量和表达式，必须实例化使用，使用sample内置函数进行采样。使用 covergroup cov coverpoint [采样变量] [when to sample]{ bins ... } endgroup创建。

自动创建仓（bin）

    1.sv会根据变量的位宽N，创建 $2^N$ 个bin，为所有可能值分别创建bin.如果可能值不是2的整数幂（例如，3bit+4bit的表达式，可能值为[0:7+15]，需创建23个bin），sv自动生成的bin不能满足需求。

    2.sv针对枚举类型，为每一个枚举值创建一个bin.
